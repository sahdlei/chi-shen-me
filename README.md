# 🍜 吃什么 chi-shen-me

> Your weekly meal planning assistant — plan your menu, track ingredients, and generate shopping lists with AI.

## Features
- 📅 Weekly meal planner with editable table
- 🛒 AI-generated shopping list
- 🥬 Ingredient freshness tracking
- 💬 AI chat assistant (Anthropic or DeepSeek)
- ⭐ Persistent personal preferences

## Deploy to Vercel

1. Fork this repo
2. Go to [vercel.com](https://vercel.com) → Import your fork
3. Deploy (no config needed)
4. Open the app, enter your API key, start planning!

## API Keys
- **Anthropic**: [console.anthropic.com](https://console.anthropic.com)
- **DeepSeek**: [platform.deepseek.com](https://platform.deepseek.com)

Keys are stored only in your browser's localStorage and sent directly to the API proxy — never stored on the server.
